# Frontend (React + Vite)

This is a minimal React scaffold that can be expanded into a full SPA. It proxies API calls to the backend (localhost:8080) when run in dev mode.

Quick start:

```powershell
cd frontend
npm install
npm run dev
```

The dev server runs on http://localhost:3000 and proxies API requests for `/students`, `/colleges`, `/placements`, `/certificates`, `/users` to the backend.
